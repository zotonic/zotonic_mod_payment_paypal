# Zotonic PayPal payment module

Payment Service Provider module for `zotonic_mod_payment` using PayPal REST Orders v2.

## Configuration

Configure these module settings in Zotonic:

* `is_live` - set to `true` for the live PayPal environment, `false` for sandbox.
* `client_id` - PayPal REST app client id.
* `secret` - PayPal REST app secret.
* `webhook_id` - PayPal webhook id used to verify webhook signatures.

## PayPal setup

Create a PayPal REST app and configure the webhook URL:

```text
https://example.com/paypal/webhook
```

Subscribe at least to these events:

* `CHECKOUT.ORDER.APPROVED`
* `CHECKOUT.ORDER.COMPLETED`
* `PAYMENT.CAPTURE.COMPLETED`
* `PAYMENT.CAPTURE.DENIED`
* `PAYMENT.CAPTURE.DECLINED`
* `PAYMENT.CAPTURE.PENDING`
* `PAYMENT.CAPTURE.REFUNDED`
* `PAYMENT.CAPTURE.REVERSED`

The checkout return URL is generated by the module as `/paypal/ready/:payment_nr`.
